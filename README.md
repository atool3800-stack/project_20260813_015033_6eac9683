## About

This project aggregates **1,000 – 10,000 GitHub events per day** (issues, pull requests,
comments and commits) and turns them into an actionable efficiency dashboard:

- ⏱️ Issue average **first response time**
- 🚀 Pull request average **merge time**
- ➕/❌ **Created / closed** counts (issues & PRs)
- 💬 **Active discussion** count
- 🏷️ **Label distribution**
- 🔥 **Top 10 active threads**

The report below is auto-generated by [`scripts/sync_metrics_to_readme.py`](scripts/sync_metrics_to_readme.py)
and refreshed on a daily schedule (see [`.github/workflows/sync-readme.yml`](.github/workflows/sync-readme.yml)).
